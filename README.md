# solar_power_forecasting_xgboost_lstm
# Dự báo năng lượng mặt trời sử dụng mô hình lai XGBoost-LSTM

## Giới thiệu

Dự án này nghiên cứu việc dự báo công suất điện mặt trời (PV) trong ngắn hạn
sử dụng các kỹ thuật học máy (machine learning) và học sâu (deep learning).

Mô hình chính là kiến ​​trúc lai XGBoost-LSTM, được phát triển dựa trên nghiên cứu của:

Kayes Bin Yousuf, Ashrafi Akter, Hadid Ahmed Noor,
Ashraful Hoque, Ashik Ahmed,
"A hybrid XGBoost-LSTM model with physics-informed features
and uncertainty quantification for solar power forecasting",
Energy Reports, 2026.

DOI: 10.1016/j.egyr.2026.109068

## Mục tiêu

- Khám phá bộ dữ liệu UNISOLAR.
- Thực hiện tiền xử lý dữ liệu và kỹ thuật đặc trưng (feature engineering).
- Triển khai mô hình dự báo XGBoost.
- Triển khai mô hình dự báo LSTM.
- Triển khai mô hình lai XGBoost-LSTM.
- So sánh hiệu suất dự báo của các mô hình khác nhau.
- Đánh giá các mô hình sử dụng các chỉ số MAE, RMSE và R².

## Bộ dữ liệu

Dự án sử dụng bộ dữ liệu năng lượng mặt trời quang điện (PV) UNISOLAR.

## Các mô hình

- Mô hình cơ sở 
- XGBoost
- LSTM
- Mô hình lai XGBoost-LSTM

## Các chỉ số đánh giá

- MAE
- RMSE
- R²
- NRMSE
- MAPE
